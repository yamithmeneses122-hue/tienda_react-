# Tienda React

Tienda virtual migrada de HTML, CSS y JavaScript a React + Tailwind CSS.

## Ejecutar

```bash
npm install
npm run dev
```

## Estructura

- `src/App.jsx`: estado del carrito y composición principal.
- `src/components/`: componentes reutilizables.
- `src/data/products.js`: catálogo de productos.
- `src/index.css`: configuración mínima de Tailwind.
